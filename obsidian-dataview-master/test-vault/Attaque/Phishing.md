# Phishing (Hameçonnage)

## Description
Technique de manipulation psychologique visant à tromper l'utilisateur pour récupérer des informations sensibles.

## Contre-mesures
- Ne jamais cliquer sur les liens suspects
- Activer l'authentification multifacteur (MFA)
## Tâches d'analyse (Phishing)
- [ ] Rédiger le scénario de test de phishing pour l'équipe 
- [ ] Documenter les indicateurs de compromission (IOC) 
- [ ] Valider les contre-mesures MFA avec l'administrateur réseau
